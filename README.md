# 🤖 Nexa N.10

Nexa N.10 is a secure AI chatbot system designed with a modular frontend and backend architecture. It connects to an AI API through a secure Node.js server, ensuring that all API keys remain private and protected.

## 🚀 Features

- 💬 Real-time AI chat interface
- 🧠 Basic memory system (session-based or localStorage)
- 🔐 Secure backend API (no exposed keys)
- 🎨 Customizable UI themes (Orange, Red, Yellow, Green, Blue, Indigo, Violet)
- 🌐 Web-based interface (runs in browser)
- ⚡ Lightweight and fast

## 🏗️ Architecture

Frontend (HTML/CSS/JS)
        ↓
Node.js Backend Server
        ↓
OpenAI API (secure key stored in .env)

## 🔒 Security

- API keys are stored in environment variables
- `.env` file is excluded using `.gitignore`
- No sensitive data is exposed to the browser
